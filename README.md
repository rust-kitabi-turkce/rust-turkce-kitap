# Rust Programlama Dili - Türkçe Çeviri

Bu proje, Resmi Rust Kitabı'nın (The Rust Programming Language) Türkçe çevirisini
içerir. Amaç: kitabı Türkçeye çevirip GitHub Pages üzerinden herkese ücretsiz
sunmak.

- Orijinal kitap: https://doc.rust-lang.org/book/
- Çeviri: https://rust-kitabi-turkce.github.io/rust-turkce-kitap/
- GitHub reposu: https://github.com/rust-kitabi-turkce/rust-turkce-kitap

## Katkıda Bulunma

Bu projeye katkıda bulunmak ister misiniz? Harika! 🎉

Katkıda bulunmadan önce lütfen [Katkıda Bulunma Rehberi](CONTRIBUTING.md)'ni
okuyun. Rehberde issue açma ve Pull Request (PR) gönderme kuralları, çeviri
kuralları ve terminoloji hakkında detaylı bilgiler bulabilirsiniz.

## Proje Durumu

Proje hala geliştirilme aşamasındadır. Çevirilerde hatalar olabilir.
Çevirisi tamamlanan bölümlerin listesi için [ceviri-durumu.md](ceviri-durumu.md)
